# Phase 4 Onboarding And Trust

## Onboarding outcomes
Users should understand:
- how DEVteam stages map to delivery work
- what they own in each stage
- how to read build, preview, and verification states
- when a project is truly launch-ready

## Component
- `SetupStepper` provides lifecycle onboarding in concise steps.

## Trust strategy
- Show readiness as checklist + verification summary.
- Keep diagnostics and sync warnings adjacent to actions.
- Do not hide ambiguous states; classify them as stale/out-of-sync.

## Professional tone
- Calm and precise wording.
- No magical language.
- Operational accountability over agent theater.
