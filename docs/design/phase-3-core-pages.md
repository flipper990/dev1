# Phase 3 Core Pages

## Product framing
DEVteam now centers the project workspace as the primary surface and uses a single lifecycle:
Decide ? Build ? Verify ? Launch.

## Page intent
- Home: orient around selected project health, stage, and next action.
- Workspace: prioritize artifact preview, unified status, evidence, and command dock.
- Projects index: portfolio view of real products with stage and health clarity.
- Activity: production evidence timeline with ownership and accountability.

## UX shifts
- Reduced chrome density and status fragmentation.
- Output/preview elevated over agent theatrics.
- One status presentation system reused across pages.
- Command dock interaction style for changes and follow-up instructions.
