# Phase 3 Workspace Layouts

## Workspace structure
1. Workspace header with unified status + primary action.
2. Preview canvas frame as hero artifact surface.
3. Lifecycle sections: Overview, Preview, Build, Verify, Launch, Activity, Logs.
4. Command dock anchored as the primary interaction for changes.
5. Optional trust/context side panel.

## Responsive behavior
- Mobile: single column, tabs and context panel become progressive disclosure.
- Tablet: workspace remains content-first with optional side context.
- Desktop: preview and evidence remain dominant; context panel optional.
- Widescreen: preserve readable max widths and avoid over-stretched layouts.

## Accessibility
- Keyboard-operable tabs and command dock.
- Live status announcement region for major state changes.
- Semantic sections and labeled landmarks.
