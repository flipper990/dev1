## Root cause chain (verified)
1. Tier 3 contract manifests were generated by `contractWorker()`.
2. `src/contracts/*` manifests were rejected during slice validation before assembly due to `ts_parse` handling.
3. Additional rejection occurred for `src/app/page.tsx` because export extraction missed `export async function` in `src/lib/api-client.ts`, causing a false `missing_named_export` on `listUsers`.
4. With rejected page, final integrity failed with `MISSING_APP_ENTRY`.

## Where artifacts were lost
- Loss happened in validation stage, not in preview/export filtering.
- Rejection points:
  - `validateSliceManifest()` TS parse path in `tier-slice-validator.ts`.
  - export extraction in `tier3-contract-runner.ts` (`extractExports` regex).

## Policy/normalization findings
- Tier 3 path policy did not forbid `src/contracts/*`.
- The main issue was pre-assembly rejection, not normalization stripping.
- Added post-assembly retention assertion for required contract paths to prevent silent drops.
